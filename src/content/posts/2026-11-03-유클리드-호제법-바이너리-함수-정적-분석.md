```
target_func:
	PUSH EBP
	MOV EBP, ESP
	SUB ESP, 12
	
	MOV DWORD PTR [EBP-4], 0
	MOV DWORD PTR [EBP-8], 0
	MOV DWORD PTR [EBP-12], 0
	
	MOV EAX, [EBP+8]
	CMP EAX, 0
	JLE LOC_FAIL
	
	MOV EBX, [EBP+12]
	CMP EBX, 0
	JLE LOC_FAIL
	
	MOV [EBP-4], EAX
	MOV [EBP-8], EBX

LOC_OUTER:
	MOV EAX, [EBP-4]
	MOV EBX, [EBP-8]
	CMP EAX, EBX
	JE LOC_MID
	
	CMP EAX, EBX
	JLE LOC_SUB_B

LOC_SUB_A:
	SUB EAX, EBX
	MOV [EBP-4], EAX
	JMP LOC_COUNT

LOC_SUB_B:
	SUB EBX, EAX
	MOV [EBP-8], EBX

LOC_COUNT:
	MOV EDX, [EBP-12]
	ADD EDX, 1
	MOV [EBP-12], EDX
	JMP LOC_OUTER

LOC_MID:
	MOV EAX, [EBP-4]
	CMP EAX, 1
	JE LOC_SPECIAL
	
	MOV ECX, [EBP-12]
	MOV EDX, [EBP+16]
	TEST EDX, EDX
	JZ LOC_PASS
	
	MOV EAX, 0

LOC_INNER:
	CMP ECX, 0
	JLE LOC_MERGE
	ADD EAX, [EBP-4]
	SUB ECX, 1
	JMP LOC_INNER
	
LOC_MERGE:
	MOV [EBP-4], EAX
	JMP LOC_PASS

LOC_SPECIAL:
	MOV DWORD PTR [EBP-4], -1

LOC_PASS:
	MOV EAX, [EBP-4]
	JMP LOC_EXIT

LOC_FAIL:
	MOV EAX, 0

LOC_EXIT:
	MOV ESP, EBP
	POP EBP
	RET
```

### 1\. 함수 시작부의 SUB ESP, 12 가 의미하는 메모리 할당 구조 작성하기 ( \[EAP-4\] , \[EBP-8\] , \[EBP-12\] 각각의 크기와 용도)

-   SUB ESP, 12 : 현재 EBP 주소에 EST가 있는데, ESP를 12바이트 작은 주소에 위치시켜 12바이트를 확보했다.
-   MOV DWORD PTR \[EBP-4\], 0 : EBP보다 4바이트 작은 주소부터 4바이트의 공간에 정수 0을 대입한다.
-   \[EBP-4\], \[EBP-8\], \[EBP-12\]는 각각 4바이트 메모리를 할당 받고 0이 대입된다.

→ 4Byte 변수 3개 선언 후 0으로 초기화한 것과 같음

### 2\. LOC\_OUTER 부터 LOC\_MID 직전까지의 코드 블록은 수학적으로 어떤 공식을 구현한 것인지 분석하기 

-   LOC\_OUTER 에서는 EAX와 EBX의 값을 CMP 후 결과에 따라 각각 3가지 함수를 호출한다.
-   두 값이 같다면 → LOC\_MID를 호출
-   EAX > EBX 라면 → LOC\_SUB\_A 호출
-   EBX > EAX 라면 → LOC\_SUB\_B 호출
-   LOC\_SUB\_A : EAX -= EBX 후 LOC\_OUTER로 돌아간다.
-   LOC\_SUB\_B : EBX -= EAX 후 LOC\_OUTER로 돌아간다
-   LOC\_SUB\_A 와 LOC\_SUB\_B 를 실행할 때마다 \[EBP-12\]의 값을 가져와 1씩 증가시킨다.

 즉 EAX와 EBX를 비교 후 두 값이 같아질 때까지 큰 값에서 작은 값을 빼는 과정을 반복한다. LOC\_OUTER부터 LOC\_MID 직전까지의 코드 블록은 유클리드 호제법을 구현한 것이다.

### 3\. LOC\_COUNT 에서 \[EBP-12\] 가 누적해서 기록하는 값의 의미는 무엇인지 찾기

LOC\_SUB\_A, LOC\_SUB\_B 가 실행될 때마다 0부터 1씩 증가시키므로 빼기 연산의 횟수를 의미한다.

### 4\. LOC\_MID 이후의 TEST EDX, EDX 와 JZ LOC\_PASS 분기문이 검사하는 매개변수는 몇 번째 인자이며, 어떤 조건일 때 분기하는지 설명하기

#### 매개변수가 몇 번째 인자인지 설명

target\_func는 호출되기 전에 받은 인자를 n번째부터 1번째까지 스택에 PUSH 해둔다. 그 다음 함수 종료 후 돌아올 위치를 PUSH한 후 target\_func로 이동하므로 \[EBP+4\]에는 함수가 종료될 위치가 들어있고, \[EBP+8\]부터 인자가 들어간다. 따라서 \[EBP+16\]에는 3번째 인자이다.

#### 어떤 조건일 때 분기하는지 설명

TEST EDX, EDX 는 EDX와 EDX를 비트단위로 & 연산한다. JZ LOC\_PASS는 이 비트 연산 결과가 0이라면 LOC\_PASS로 점프한다는 의미이다.

EDX와 EDX는 같은 값이므로 비트 & 연산을 해도 항상 EDX가 나온다. 따라서 LOC\_MID 이후의 TEST EDX, EDX 와 JZ LOC\_PASS 분기문은 EDX가 0일 때를 기준으로 EDX가 0이라면 LOC\_PASS로 점프하고, 0이 아니라면 EAX에 0을 넣고 LOC\_INNER로 넘어간다.

### 4\. LOC\_INNER 루프는 어떤 연산을 수행하고 있는지 수식으로 표현하기

이전에 0이 대입된 EAX에 ECX, 즉 SUB 연산의 횟수만큼 EAX += \[EBP-4\]를 수행하고 있다. \[EBP-4\]를 ECX 값 만큼 더하고 있으므로 LOC\_INNER 루프는 곱셈 연산을 수행하고 있다.

ECX : N이라고 할 때  
EAX : \[EBP-4\] \* N

### 5.  \[손계산\]

#### a. target\_func(15, 6, 0) 호출 시 최종 반환값 EAX 구하기 (중간 \[EBP-12\] 값도 쓰기)

15, 6, 0은 각각 \[EBP+8\], \[EBP+12\], \[EBP+16\]이다. 15-6=9 계산할 때 \[EBP-12\]=1, 9-6=3 계산할 때 \[EBP-12\]=2, 6-3=3 계산할 때 \[EBP-12\]=3으로, LOC\_MID 직전에 각 메모리 값은 \[EBP-4\] = \[EBP-8\] = 3, \[EBP-12\]=3

LOC\_MID에서

EAX=3으로 1이 아니므로 ECX=3, EDX=0  
EDX는 0이므로 LOC\_PASS로 점프한다.LOC\_EXIT에서 EST가 함수가 호출된 자리를 가리키면서 함수가 종료되고, 3을 반환한다.

LOC\_PASS에서  
EAX=3, LOC\_EXIT로 점프한다

LOC\_EXIT에서 EST가 함수가 호출된 자리를 가리키면서 함수가 종료되고, 3을 반환한다.

#### b. target\_func(15, 6, 1) 호출 시 최종 반환값 EAX 구하기

LOC\_MID 직전까지 a와 과정이 동일하므로 이때 각 메모리에 저장된 값은 \[EBP-4\] = \[EBP-8\] = 3, \[EBP-12\]=3

LOC\_MID 에서  
EAX=3으로 1이 아니므로 ECX: 3, EDX: 0  
EDX는 0이 아니므로 EAX: 0, LOC\_INNER로 이동한다.

LOC\_INNER에서는 ECX값을 1씩 줄이며 0이 될 때까지 EAX += \[EBP-4\] 를 계산한다. ECX=3, \[EBP-4\]=3이므로 EAX = 3\*3 = 9, ECX가 0이므로 LOC\_MERGE로 점프한다.

LOC\_MERGE 에서  
\[EBP-4\]에 9 대입 후 LOC\_PASS로 점프한다.

LOC\_PASS 에서 EAX에 9 대입 후 LOC\_EXIT로 이동해 함수가 종료되고, 9가 반환된다.

#### c. target\_func(7, 9, 1) 호출 시 최종 반환값 EAX 구하기

7, 9, 1은 각각 \[EBP+8\], \[EBP+12\], \[EBP+16\]이다. 9-7=2, 7-2=5, 5-2=3, 3-2=1, 2-1=1 이므로 LOC\_MID 직전에 각 메모리에 저장된 값은 \[EBP-4\] = \[EBP-8\] = 1, \[EBP-12\]=5

LOC\_MID에서  
EAX=\[EBP-4\]=1로 EAX가 1이므로 LOC\_SPECIAL로 점프한다.

LOC\_SPECIAL에서 \[EBP-4\]의 4바이트 공간에 -1을 대입한 후 LOC\_PASS로 이동한다.

LOC\_PASS에서  
EAX=-1 대입 후 LOC\_EXIT로 이동해 함수가 종료되고, -1을 반환한다.

### 6\. \[C언어 디컴파일\] 위 어셈블리 코드 전체를 if-else, while, for 문만을 사용하여 C언어 함수로 복원하기

```
#include <stdio.h>

int target_func(int x, int y, int d) {      //[EBP+8], [EBP+12], [EBP+16]
    int a=0, b=0, c=0;          //[EBP-4], [EBP-8], [EBP-12]

    if(x<=0) {
        //LOC_FAIL
        a=0;
    }
    
    else if(y<=0) {
        //LOC_FAIL
        a=0;
    }

    else{
        a=x, b=y;

        //LOC_OUTER:
        while(1){

            if(a==b) {
                //LOC_MID
                break;
            }
            else {
                if(a>b) {
                    //LOC_SUB_A
                    a -= b;
                    c++;
                }
                else {
                    //LOC_SUB_B
                    b -= a;
                    c++;
                }
            }
        }

        //LOC_MID:
        if(a==1) {
            //LOC_SPECIAL
            a=-1;
        }
        else{
            if(d==0){
                //LOC_PASS
                
            }
            else{
                //LOC_INNER:
                int EAX=0;  //register 용도의 변수 선언
                int ECX=c;
                while(1){
                    if(ECX<=0){
                        //LOC_MERGE
                        break;
                    }
                    EAX += a;
                    ECX--;
                }
                
                //LOC_MERGE:
                a = EAX;
            }
            //LOC_PASS
        }
    }

    //LOC_PASS
    return a;

    //LOC_EXIT:
}


int main(void) {
    int x = target_func(15,6,0);
    int y = target_func(15,6,1);
    int z = target_func(7,9,1);
    printf("%d, %d, %d \n", x, y, z);   //3, 9, -1 출력

    return 0;
}
```
